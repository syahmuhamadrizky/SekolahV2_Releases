v2.13.4
- Penyempurnaan Registrasi Siswa Baru & Proteksi Integritas Rombel:
  1. Validasi Wajib Kelas / Rombel: Menjadikan pilihan Kelas / Rombel sebagai kolom wajib pada form tambah siswa agar setiap siswa baru langsung terikat ke anggota_rombel, tahun pelajaran, dan semester aktif Dapodik.
  2. Auto-Focus Siswa Baru: Setelah simpan data siswa baru berhasil, filter kelas otomatis di-reset ke 'Semua Kelas' dan kolom pencarian otomatis memfilter nama siswa baru tersebut agar langsung muncul di baris paling atas.
  3. Anti-Cache Global API Middleware: Menambahkan header Cache-Control (no-store, no-cache, must-revalidate) pada seluruh rute /api/* di server.ts agar pembaruan data selalu instan tampil di browser tanpa tertahan cache.

v2.13.3
- Sistem Rekonsiliasi Cerdas Siswa Pindahan / Manual ke Dapodik Resmi:
  1. Auto-Reconciliation Berbasis NIK/NISN: Saat sinkronisasi Dapodik berjalan, sistem secara cerdas mencocokkan siswa baru Dapodik dengan siswa yang sempat diinput manual berdasarkan NIK (16 digit) atau NISN.
  2. Migrasi Seluruh Nilai & Aktivitas Otomatis: Jika kecocokan ditemukan, seluruh nilai ASTS, formatif, proyek P5 kokurikuler, absensi, riwayat kelas, dan data ujian yang terikat pada ID manual otomatis dialihkan ke ID resmi Dapodik tanpa tercecer/hilang.
  3. Anti-Duplikasi 100%: Mencegah terjadinya data siswa ganda (double), ID manual di-upgrade otomatis ke ID Dapodik resmi yang valid.
  4. Endpoint Rekonsiliasi Mandiri: Disediakan endpoint POST /api/students/reconcile-dapodik bagi administrator untuk mengecek dan menyelaraskan data siswa kapan saja.

v2.13.2
- Perbaikan & Penyempurnaan Cetak Rapor Kokurikuler (P5):
  1. Perbaikan Kueri Rapor Siswa: Memperbaiki relasi SQL JOIN pada tabel ptk (ptk_id) saat mengambil data wali kelas rombel sehingga lembar cetak rapor kokurikuler siswa dapat dimuat tanpa kendala / tidak kosong.
  2. UI Fallback & Retry State: Menambahkan tampilan notifikasi ramah dan tombol muat ulang jika lembar rapor sedang tidak memuat data atau filter belum sesuai.
  3. Peningkatan Stabilitas Cetak Rapor: Memastikan data rombel, sekolah, proyek, dan penilaian 3 pilar per siswa terintegrasi secara mulus.

v2.13.1
- Cetak Rapor Kokurikuler (P5) Individual Per Siswa (Kurikulum Merdeka):
  1. Filter Lengkap Tahun Pelajaran & Semester: Modal cetak dilengkapi filter Tahun Pelajaran, Semester (1 Ganjil / 2 Genap), Rombel, serta Pilihan Siswa (cetak per siswa atau cetak massal 1 kelas).
  2. Seluruh Kegiatan Kokurikuler Terangkum Otomatis: Seluruh proyek kokurikuler yang terdaftar sesuai tingkat kelas / fase di semester & tahun ajaran tersebut otomatis masuk menjadi satu lembar rapor per siswa.
  3. Format Standar Resmi A4 Kurikulum Merdeka: Lembar rapor individual per siswa dilengkapi Kop Surat Resmi Sekolah, Biodata Siswa, Matriks Penilaian 3 Pilar (Karakter P5, Proses & Partisipasi, Hasil Karya & Portofolio), Catatan Narasi Capaian Karakter, Legenda Predikat (BB, MB, BSH, SB), serta 3 Kolom Tanda Tangan Resmi (Orang Tua, Kepala Sekolah, Guru Kelas / Wali Kelas).
  4. Isolasi Fase Ketat 100%: Kegiatan kokurikuler terisolasi penuh sesuai fase tingkat kelas (contoh: Proyek Fase A untuk Kelas 1 & 2 tidak akan tampil/bocor di Kelas 3A Fase B), dilengkapi panduan visual otomatis jika belum ada proyek untuk fase kelas yang dipilih.
  5. Tombol Cetak Cepat Tiap Siswa: Disediakan tombol cetak rapor langsung di samping nama masing-masing siswa pada tabel penilaian.
